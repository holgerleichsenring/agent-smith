# Concepts

The core ideas behind Agent Smith.

- **[Pipeline system](pipeline-system.md)**: commands, handlers, presets, and how they chain together
- **[Phases & runs](phases-and-runs.md)**: how Agent Smith tracks its own work, from planning to execution and results
- **[Self-documentation](self-documentation.md)**: phases, runs and decisions as an audit trail
- **[Decision logging](decisions.md)**: why the agent made each choice, not just what it did
- **[Cost tracking](cost-tracking.md)**: token usage, pricing, and result.md frontmatter
- **[Interactive dialogue](interactive-dialogue.md)**: structured Q&A between agent and human across all channels
- **[Knowledge base](knowledge-base.md)**: an LLM-compiled project wiki from accumulated run records
- **[Memory](memory.md)**: facts the agent keeps across runs
