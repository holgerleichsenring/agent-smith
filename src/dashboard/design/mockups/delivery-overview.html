  • Each run already stores StartedAt, DurationSeconds, EndKind, CostTotalUsd and its PRs. Each spec stores its status and verdict. List queries and hub groups are already filtered by project.

  • Time to merge reads the merge time each pull request record already stores. Rework rounds read why each attempt began, which each attempt row already stores. The ticket outcome is the bucket the Tickets page shows.
